# 看见大脑的变化 V4.2 科普版
软件开发：苏裕盛 教授/医学博士

## 如何更新
只需将本包的 index.html 上传到原 brain-ad-3d 仓库根目录，覆盖旧文件。
本文件包含全部程序与模型，无需上传vendor或其他依赖。
同一网址：https://sueivan.github.io/brain-ad-3d/
上传后等待GitHub Pages完成部署，再按Ctrl+F5刷新。网页顶部应出现“交互科普版 V4.2”。
本机也可直接双击index.html，浏览器需支持WebGL并开启硬件加速。

## 科普内容
双脑同步旋转、放大，三个重点：脑回变瘦/脑沟变宽、海马变小、脑室变大。
点击海马或脑室按钮后，外部结构半透明，金色海马或蓝色侧脑室显现，标签跟随三维投影位置。
外观和变化均为解剖图谱基础上的教学示意，不是患者MRI、不对应任何疾病分期或萎缩率，不能诊断AD。
