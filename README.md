# 看见大脑的变化 V5.0 视觉增强版
软件开发：苏裕盛 教授/医学博士

## 更新方法
解压后，将 index.html 上传到原 brain-ad-3d 仓库根目录，覆盖旧文件。
网页、模型及程序均包含在 index.html 内，不需要上传其他依赖。
README.md、MODEL_LICENSE.txt、THREE_LICENSE.txt建议保留并同步更新。
地址继续使用 https://sueivan.github.io/brain-ad-3d/ 。等待GitHub Pages部署完成后刷新，顶部应显示“视觉增强版 V5.0”。
本地也可直接双击index.html；浏览器需要支持WebGL和硬件加速。

## 根据录屏改进
1. 外观：按真实网格顶点范围调整取景，减少留白；调整柔和主光、补光和轮廓光，统一粉色材质。皮质形变收敛，减少人为拉开脑回造成的破碎感。保持左右同一显示尺度。
2. 海马：选择后只突出金色海马，隐藏蓝色脑室，脑轮廓减淡；单击“放大重点”可以单独比较，返回后恢复全脑定位。
3. 脑室：只突出蓝色侧脑室，隐藏海马；正常与AD使用同一放大尺度。
4. 动作：自动旋转放慢；手动拖动、选择结构或固定视角会暂停自动旋转；视角平滑过渡，并尊重系统减少动态效果设置。
5. 文字：标签增大、对比度提升，保留左右说明对齐及手机上下布局。
6. 科普分享：点击“保存对比图”导出2000×1320 PNG，包含当前主题、两侧模型、软件署名、模型来源、许可地址和示意性质说明。

## 医学与模型边界
这是通用解剖网格基础上的科普示意，不是真实患者的MRI或随访数据。
AD侧为人工教学形变，方向作示意性突出，不对应任何临床测量、萎缩率或分期，也不能用于诊断。
颜色用于定位：海马为金色、侧脑室为蓝色；不代表实际组织颜色。
