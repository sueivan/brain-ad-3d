软件开发：苏裕盛 教授/医学博士

## 更新方法
解压后，将 index.html 上传到原 brain-ad-3d 仓库根目录，覆盖旧文件。
网页、模型及程序均包含在 index.html 内，不需要上传其他依赖。
README.md、MODEL_LICENSE.txt、THREE_LICENSE.txt建议保留并同步更新。
地址继续使用 https://sueivan.github.io/brain-ad-3d/ 。等待GitHub Pages部署完成后刷新，顶部应显示“细胞动画版 V7.2”。
本地也可直接双击index.html；浏览器需要支持WebGL和硬件加速。

## 新增网页内嵌动画
细胞与连接部分已替换为32秒、1920×1080中文科普动画，配有播放/暂停/进度/全屏控件及折叠文字要点。手机支持页内播放。不自动播放。
视频和首帧海报均内嵌在index.html中，只上传index.html即可，无需另外上传MP4或GIF。页面顶部新增动画跳转入口。
动画四个观察分镜不对应病程四阶段，不表示固定发生顺序；视频为程序绘制机制示意，非显微实拍。

## 保留四步形态差异
- 增强脑回局部变瘦与整体皮质轮廓回缩，四步的几何形态均有递进差异。
- 手动点击阶段立即切换；自动播放保留平滑过渡。
- 补回原始BodyParts3D图谱左右大脑白质网格作为脑沟下方的连续组织。外观显示，内部结构模式隐藏；这些也是解剖图谱结构，非患者测量。
- 正常参照与镜头尺度固定；随阶段更新右侧表面观察标签及说明。
- 这套四步是视觉增强的科普叙事，不是四种标准临床脑图。初现与轻度可重叠，形变参数未按患者随访数据标定。

## 保留五组脑区与细胞示意
- 海马旁回：图谱实际网格，不作为内嗅皮质的精确分割。
- 颞叶、顶叶、额叶：按图谱region分组高亮，单独放大对照。
- 后扣带回与楔前叶：按Posterior dorsal / Posteroventral cingulate及Precuneus名称选择，排除middle posterior cingulate。
- 五组区域均可配合四个病程按钮观察。颜色只标示选中的解剖区域，不是病理或PET热图。形变未经临床数据标定，不表示所有患者受累位置、程度和顺序一致。
- 细胞层面独立SVG概念图：突触与神经元受损，细胞外淀粉样斑块、细胞内Tau缠结。图中数量与病程按钮无对应关系。
- 科普依据：https://www.nia.nih.gov/health/alzheimers-causes-and-risk-factors/what-happens-brain-alzheimers-disease
- 脑区功能：https://www.alzheimers.org.uk/about-dementia/stages-and-symptoms/areas-of-the-brain
- 区域性皮质变薄研究：https://pmc.ncbi.nlm.nih.gov/articles/PMC1853284/

## 保留病程演示
点击“症状初现、轻度、中度、重度”切换右侧模型，左侧正常参照不变。点击“播放变化”自动演示；手动选择阶段会停止播放。保存对比图会采用当前所选阶段的完整形态并标注阶段。
阶段只组织科普叙事：症状初现与轻度可重叠，并非独立临床分期。几何形变采用人工插值，未按临床纵向数据标定，不能作为各阶段的标准脑图。没有固定年份与形态对应关系，重度不等于临终。
病程参考：https://www.alz.org/alzheimers-dementia/stages

## 保留功能
1. 外观：按真实网格顶点范围调整取景，减少留白；调整柔和主光、补光和轮廓光，统一粉色材质。皮质形变收敛，减少人为拉开脑回造成的破碎感。保持左右同一显示尺度。
2. 海马：选择后只突出金色海马，隐藏蓝色脑室，脑轮廓减淡；单击“放大重点”可以单独比较，返回后恢复全脑定位。
3. 脑室：只突出蓝色侧脑室，隐藏海马；正常与AD使用同一放大尺度。
4. 动作：自动旋转放慢；手动拖动、选择结构或固定视角会暂停自动旋转；视角平滑过渡，并尊重系统减少动态效果设置。
5. 文字：标签增大、对比度提升，保留左右说明对齐及手机上下布局。
6. 科普分享：点击“保存对比图”导出2000×1320 PNG，包含当前主题、两侧模型、软件署名、模型来源、许可地址和示意性质说明。

## 医学与模型边界
这是通用解剖网格基础上的科普示意，不是真实患者的MRI或随访数据。
AD侧为人工教学形变，方向作示意性突出，不对应任何临床测量、萎缩率或分期，也不能用于诊断。
颜色用于定位：海马为金色、侧脑室为蓝色；不代表实际组织颜色。
